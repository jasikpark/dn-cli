# Agent notes

Read [CONTRIBUTE.md](./CONTRIBUTE.md) for the build, test, and release flow.

- PR titles are conventional commits (`feat:`, `fix:`, `test:`, ...); squash
  merges keep only the title.
- A change users should read about also needs a `.changeset/<short-name>.md`
  change file. The format is in CONTRIBUTE.md under "Changelog and releases".
